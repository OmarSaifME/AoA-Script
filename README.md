# AoA Python Script
To streamline the calculation process of setting up an 'angled' flow in ANSYS Fluent, I have developed a simple Python script that takes the freestream velocity and Angle of Attack as inputs, and derives the 6 settings values needed to manipulate the flow conditions as desired. A 'GUI' wrapped version of this script is available in my Reynold's App, but I still opened this repository for the 'tech-savvy' audience.

A document file is added for further clarification on the script, and how to address each values and port them to the settings of Fluent.
